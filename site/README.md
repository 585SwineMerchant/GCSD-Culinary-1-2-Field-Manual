# GCSD Culinary Arts 1 & 2 Field Manual

The student-facing digital field manual for GCSD Culinary Arts 1 & 2.

The site includes course units, lesson preparation and reflection prompts,
recipes, culinary quick references, vocabulary definitions, and browser-saved
student progress.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

GitHub Actions publishes the `main` branch to GitHub Pages.
