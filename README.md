# GCSD Culinary Arts 1 & 2 Student Field Manual

This repository is the durable working environment for continued development of the Greece Central School District Culinary Arts 1 & 2 Student Field Manual.

## Purpose

The field manual is a student-facing reference that supports the existing Culinary 1 & 2 instructional sequence. It is intended to help students prepare for class, review foundational knowledge, plan labs, reflect on performance, and build toward more advanced culinary experiences.

This repository supports:

- independent iteration outside ChatGPT;
- collaboration with Culinary Pathway team members;
- version control and review through branches and pull requests;
- future automation through GitHub Actions;
- preservation of the sources and design decisions that shaped the manual.

## Repository Structure

- `manual/` — current working manual and archived reference versions
- `recipe-book/` — recipe-book references used alongside the manual
- `sources/curriculum/` — course outlines, scope and sequence, and instructional source documents
- `sources/assessment/` — employability and skills-map references
- `sources/project-context/` — design rationale and project context
- `governance/` — source register, status notes, and collaboration guidance
- `site/` — future web version of the field manual
- `.github/` — issue templates, pull-request guidance, and future Actions workflows

## Current Status

The repository is being initialized from the completed Version 1.0 field manual and the source materials used in its development. Version 1.0 is retained as a reference point rather than treated as the final architecture.

The next production phase will establish the web structure, convert approved manual content into maintainable source files, and create a controlled workflow for review and publication.

## Core Guardrail

Do not reinvent the curriculum. Preserve the existing instructional sequence, explain why it works, and improve clarity, usefulness, accessibility, and maintainability without replacing established course design.

## Document Status

Materials in this repository are planning and instructional-development materials unless explicitly identified as adopted district curriculum or policy.
