## Source-Control Rules

1. The course outline governs the instructional sequence.
2. The field manual explains and supports the curriculum; it does not replace the curriculum.
3. Recipe files support instruction but do not independently define unit order or required competencies.
4. Historical documents must retain their dates and status.
5. When a source is revised, preserve the prior version in an archive or release rather than silently replacing the record.
6. Do not upload student-identifiable records, confidential evaluations, restricted district materials, copyrighted commercial curriculum, or credentials that the district is not authorized to redistribute.

## Binary-File Transition Note

The source copies above are retained in Google Drive while the repository is initialized. GitHub should ultimately contain approved repository copies or release assets for the field manual and recipe book, alongside editable Markdown or structured source files. The editable repository source—not a binary Word or PDF file—should become the long-term basis for website generation and collaborative revision.
